# Troubleshooting Guide (#482)

## Common Issues & Resolutions

### 1. Freighter Extension Not Detected

Ensure Freighter is unlocked and permission is granted for the current origin.

### 2. Network Mismatch Warning

Verify that the selected network in TxWatch matches the active network configured in Freighter.

### 3. Webhook Delivery Failures

Check webhook endpoint connectivity and ensure the target server accepts POST requests with JSON payloads.
